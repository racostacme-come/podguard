# PODGuard

An original computational mechanics study of POD/Galerkin heat surrogates with
online residual error bounds. Implementation and validation are in progress.

Grounded in local AI in COME topics (PCA/POD and surrogate modeling) and the
elliptic discretization concepts shared by AFEM and CFD. Only course filenames
were inspected. All code, synthetic loads, experiments and prose are original.
